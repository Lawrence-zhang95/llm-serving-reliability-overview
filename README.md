# LLM Serving Reliability under Workload Shift

**Independent AI Research | Python · Machine Learning · LLM Systems**

## Overview

This independent research project investigates the reliability of predictive models for large language model (LLM) serving performance under changing workloads and model configurations.

Predictive models can support performance estimation, but their reliability may deteriorate when operating conditions differ from those encountered during development. The project explores how uncertainty and robustness assessment can inform decisions about when predictive estimates should be supplemented by direct measurement.

## Research Objectives

- Investigate predictive modelling for LLM inference performance.
- Examine the effects of workload and model distribution shift.
- Evaluate uncertainty, predictive reliability and robustness.
- Explore uncertainty-aware benchmarking decisions.

## Technical Areas

- **Programming:** Python
- **Machine Learning:** Predictive modelling, uncertainty quantification, distribution-shift evaluation and model robustness
- **LLM Systems:** Inference latency, throughput, serving performance and benchmarking
- **Research Methods:** Experimental design, statistical analysis and quantitative evaluation

## Research Status
